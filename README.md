# Wesdecky by Weirdstore.vn

Plugin [Decky Loader](https://decky.xyz) cho Steam Deck / SteamOS, gộp 3 công cụ trong một menu:

| Tab | Làm gì |
|---|---|
| **Việt hóa** | Tìm, tải, cài và gỡ bản Việt hóa cho game Steam |
| **eGPU** | Cho game chạy bằng eGPU khi đang cắm, tự về GPU trong máy khi rút |
| **DNS** | Đổi DNS cho Wi-Fi/Ethernet (Cloudflare, Google, hoặc bộ DNS tự lưu) |

## Tải về

**[⬇ Tải wesdecky.zip (bản mới nhất)](https://github.com/whynot4444/wesdecky-download/raw/main/wesdecky.zip)**

## Cài đặt ngay trên Steam Deck (Game Mode)

1. Đã cài Decky Loader.
2. Bấm `...` → tab Decky (biểu tượng ổ cắm) → bánh răng → **General** → bật **Developer mode**.
3. Vào tab **Developer** → **Install Plugin From URL**, dán link:

   ```
   https://github.com/whynot4444/wesdecky-download/raw/main/wesdecky.zip
   ```

   Hoặc tải file zip về rồi chọn **Install Plugin from ZIP**.
4. Mở `...` → Decky → **Wesdecky**.

Cập nhật: làm lại bước 3, link trên luôn trỏ tới bản mới nhất.

## Chuyển từ plugin cũ

Nếu đang dùng **All in 1 by Weirdstore.vn**, **Viet Hoa**, **eGPU Switcher** hoặc **DNS Changer by Weirdstore.vn**: cài Wesdecky, mở một lần (sao lưu Việt hóa và bộ DNS đã lưu được tự chuyển sang), rồi mới gỡ plugin cũ. Gỡ DNS Changer cũ sẽ trả DNS về mặc định, chọn lại DNS ở tab **DNS**.
